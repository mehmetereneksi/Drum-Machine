# Drum Machine 🥁

A web-based, interactive Drum Machine built with HTML, CSS, and Vanilla JavaScript. This project allows users to play different drum sounds either by clicking the on-screen pads or by pressing the corresponding keys on their keyboard. 

## ✨ Features

* **9 Interactive Drum Pads:** Play different audio clips (Kick, Clap, Hi-Hat, etc.).
* **Keyboard Support:** Trigger sounds using the `Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X`, and `C` keys.
* **Power Switch:** Toggle the drum machine on and off. When turned off, pads and keys are disabled.
* **Volume Control:** Adjust the audio output level using the volume slider.
* **Dynamic Display:** Shows the name of the currently playing audio clip or the current volume level.
* **Responsive Design:** Clean, centered UI with active states for button presses.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and audio elements.
* **CSS3:** Styling, Flexbox, CSS Grid, and custom range sliders.
* **JavaScript (ES6+):** DOM manipulation, event listeners (click and keydown), and audio control.
